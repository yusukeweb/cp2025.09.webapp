# Next.js × GitHub 共同開発 練習用サイト

このリポジトリは、**GitHub を使ったチーム開発の流れ**を学ぶための練習用プロジェクトです。

- clone
- branch 作成
- ファイル追加 / 編集
- commit / push
- Pull Request

までを一通り体験することを目的としています。

---

## 使用技術

- Next.js（App Router）
- JavaScript
- CSS Modules

---

## 開発環境の準備

```bash
npm install
npm run dev

ブラウザで以下にアクセスしてください。
http://localhost:3000
